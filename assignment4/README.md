# Assignment 4 — Reweighing Fairness Evaluation

This project evaluates the **Reweighing** preprocessing algorithm (Kamiran & Calders, 2012) on three datasets using [AIF360](https://github.com/Trusted-AI/AIF360) and logistic regression.

## Files and Data

```text

├── requirements.txt

```

The raw datasets are downloaded separately (not included in the repository). Place them as shown above:

- [Adult Census Income](https://archive.ics.uci.edu/dataset/2/adult): `adult.data`, `adult.test`
- [German Credit](https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data): `german.data`
- [COMPAS](https://github.com/propublica/compas-analysis/blob/master/compas-scores-two-years.csv): `compas-scores-two-years.csv`

## Run the Experiment

1. Open the `assignment4` folder in **VS Code** and select a **Python 3.12** environment.
2. Install dependencies in the selected environment:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Open `fairness_evaluation.ipynb` and select the same Python kernel.
4. Select **Restart Kernel and Run All**, then save the notebook with its outputs.

The notebook writes three files to `results/`: `fairness_metrics.csv`, `fairness_changes.csv`, and `experiment_config.csv`.

## Experimental Setup

| Setting | Value |
| --- | --- |
| Datasets / protected attributes | Adult / sex; German Credit / age; COMPAS / race |
| Favorable outcomes | Income >$50K; good credit; no two-year recidivism |
| Split | 80% train / 20% test; stratified by protected group and label |
| Random seed | 42 |
| Classifier | `LogisticRegression(C=1.0, solver="lbfgs", max_iter=2000)` |
| Mitigation | AIF360 `Reweighing`, applied to training samples only |
| Evaluation | DP_Diff, DIR, 5-neighbor Consistency, Accuracy, F1, Balanced Accuracy |

The target protected attribute is excluded from the classifier features. Baseline and reweighed models are evaluated on the same held-out test set. The notebook also reports fairness metrics for the original labels.
